# agoraford-ui

Shared UI library and design system (`@agoraford/ui`) for all Agoraford projects: mojaboard, case-ms-v2, community-cms, e-disclosure, laatweet.

**Status:** planning. See [docs/BLUEPRINT.md](docs/BLUEPRINT.md) for the problem, solution, design system, steps and edge cases.

## Rules
- Tailwind CSS + Radix-based components + design tokens only.
- **Ant Design (`antd`) is banned in every project.**
- Library has no business logic or API calls. UI only.
